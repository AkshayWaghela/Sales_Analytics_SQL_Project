# Quick Start

1. Read `README.md` and `docs/DATA_DICTIONARY.md`.
2. Use a test Supabase project/database. The schema script drops existing project tables/views before recreating them.
3. Run SQL files in this order: schema, sample data, views, analysis, data quality, dashboard queries, business case.
4. Validate table counts and run a few core queries.
5. Review `docs/ANALYSIS_AND_LIMITATIONS.md` before writing portfolio claims.
6. Use `docs/INTERVIEW_GUIDE.md` to prepare to explain the SQL and assumptions.

No dashboard setup is required to review or showcase the SQL project. Dashboard-query SQL is retained as evidence of reporting readiness, but the project can stand alone as a database and analytics case study.
